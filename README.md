# 圣杯战争｜冬木档案

《Fate》世界观的非官方中文设定展。以第四次冬木圣杯战争的小圣杯为三维展品，收录冬木五次战争、仪式结构、令咒、常规职阶、御主名录与代表性世界线变体。关键剧透默认折叠，各档案附来源。

## 本地运行

使用 Node.js 22.12 或更高版本。在项目目录执行：

```powershell
npm.cmd ci
npm.cmd run dev
```

用浏览器打开终端显示的本地地址。执行 `npm.cmd run build` 生成可部署的 `dist`，执行 `npm.cmd run preview` 可检查构建结果。

## 展品操作

拖拽或使用方向键旋转。通过滚轮、双指或加减键调整距离，点选杯体或按回车打开说明。展厅底部另有自动旋转和视角重置。无法启用 WebGL 2 时显示静态渲染。

展品参考《Fate/Zero》中的金色小圣杯，金属纹饰为展陈演绎。作品、角色及相关图样权利归原权利方。

## 背景音乐

展厅循环播放梶浦由記的《count it from zero》。进入页面时以50%音量尝试自动播放。若浏览器拦截有声自动播放，可点击页眉的播放按钮。音乐权利归原权利方。
